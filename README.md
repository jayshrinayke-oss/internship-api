# Internship REST API

A beginner-friendly REST API built using Node.js, Express.js, and SQLite for managing internship records.

## Technologies Used

- Node.js
- Express.js
- SQLite
- better-sqlite3

## Features

- Get all internships
- Pagination
- Get internship by ID
- Create a new internship
- Update an internship
- Delete an internship
- Input validation
- Persistent data storage using SQLite
